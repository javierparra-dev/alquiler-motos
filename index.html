Acerca del proyecto

MotoFlow Optimizer es una demo de arquitectura por capas: la web en el navegador, el backend en PHP y el cálculo pesado en un motor C++.

PHP C++ JavaScript MySQL HTML / CSS WebAssembly (próximo)

Frontend

HTML, CSS y JavaScript para el mapa en vivo y la interacción. Diseño "Cyber-Tech" oscuro inspirado en sistemas monocromáticos modernos.

Backend (PHP)

Recibe las solicitudes del usuario, valida formularios y guarda los datos básicos: motos, usuarios y viajes.

Motor (C++)

El ejecutable que PHP invoca para el cálculo pesado. Algoritmos previstos:

  • Rutas óptimas entre punto A y punto B.
  • Tarifas dinámicas según oferta/demanda y clima.
  • Predicción de desgaste y mantenimiento (km y horas de uso).
  • Priorización de motos más nuevas al asignar flota.

Datos

Por ahora todo corre con datos simulados en data/motos.json. El paso siguiente es conectar la base de datos real y el motor C++ compilado a WebAssembly.
